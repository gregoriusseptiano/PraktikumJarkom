# Praktikum Jaringan Komputer

Repositori ini berisi kumpulan tugas, latihan, dan proyek akhir (UAS) dari mata kuliah Praktikum Jaringan Komputer (Semester 4). 

## 📂 Struktur Repositori

Repositori ini diorganisasikan berdasarkan pertemuan praktikum:

* **Pertemuan 2 - 8**: Berisi tugas, laporan praktikum (format `.pdf` atau `.docx`), dan file topologi simulasi jaringan Cisco Packet Tracer (`.pkt`).
* **UAS Jarkom**: Berisi dokumen laporan akhir dan file topologi jaringan kompleks yang dikerjakan sebagai Ujian Akhir Semester.
* **.github**: Berisi konfigurasi terkait workflow GitHub (jika ada).

## 🛠️ Tools yang Digunakan

* **Cisco Packet Tracer**: Digunakan untuk merancang, mengonfigurasi, dan menyimulasikan topologi jaringan.
* **Pengolah Kata (Word/PDF Editor)**: Digunakan untuk penyusunan laporan dokumentasi setiap praktikum.

## 🚀 Cara Menggunakan

1. Clone repositori ini ke dalam perangkat lokal Anda menggunakan Git:
   ```bash
   git clone <url-repositori-anda>
   ```
2. Navigasi ke folder pertemuan yang ingin Anda pelajari (misal: `Pertemuan 2`).
3. Buka file ber-ekstensi `.pkt` menggunakan aplikasi **Cisco Packet Tracer**.
4. Buka file `.pdf` atau `.docx` untuk membaca laporan langkah-langkah konfigurasi dan pengujian yang telah dilakukan.
